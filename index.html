📚 Conceptos Fundamentales de Python

1. print() con y sin comillas

Las comillas definen una cadena de texto (String). Sin comillas, Python evalúa variables o realiza números/cálculos.

print("Hola Mundo") # Texto directo
print(10 + 5)        # Imprime 15

2. input(), int() y float()

input() ingresa datos como texto. Usamos int() para enteros y float() para decimales.

edad = int(input("Edad: "))
precio = float("150.50")
print("Total:", precio * 2)

3. Listas, bucle for y promedios

Para calcular promedios recorremos la lista con un bucle for acumulando la suma, o usamos sum() / len().

notas = [8, 9, 7, 10]
suma = 0
for n in notas:
    suma = suma + n
promedio = suma / len(notas)
print("Promedio:", promedio)

4. Módulos en Python

Importamos módulos con import para usar funciones avanzadas como math.sqrt() o random.randint().

import math
import random

print("Raíz de 16:", math.sqrt(16))
print("Dado:", random.randint(1, 6))

5. Toma de Decisiones (if / else)

Permite que el programa tome diferentes caminos según se cumpla una condición. ¡Atención a los cuatro espacios de sangría (indentación)!

nota = 7
if nota >= 6:
    print("¡Materia Aprobada!")
else:
    print("Debes Desaprobar")

6. Funciones Personalizadas (def)

Definimos bloques de código reutilizables usando la palabra clave def seguida del nombre de la función y paréntesis.

def saludar(nombre):
    print("¡Hola", nombre, "bienvenido al taller!")

saludar("Martín")
saludar("Sofía")
